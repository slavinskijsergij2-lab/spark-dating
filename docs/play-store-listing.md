## Страница в магазине

**Название (≤30):** Spark Dating

**Краткое описание (≤80):** Знакомства для серьёзных отношений: свайпы, взаимные лайки и чат

**Полное описание (≤4000):**

Spark — приложение для знакомств, где важны настоящие люди и живое общение.

Как это работает:
• Заполни профиль: имя, возраст, фото и пару слов о себе
• Свайпай анкеты людей из твоего города
• Взаимный лайк — это матч. Пишите друг другу в чате!

Что внутри:
• Анкеты с несколькими фото и описанием
• Фильтры по возрасту, городу и целям знакомства
• Чат с ответами на сообщения и фото
• Истории — покажи, как прошёл твой день
• Совместимость по короткому квизу
• Уведомления о новых матчах и сообщениях

Безопасность:
• Пожаловаться на анкету или заблокировать пользователя можно в один клик
• Жалобы проверяет модерация, нарушители блокируются
• Только для совершеннолетних: 18+
• Удалить аккаунт и все данные можно в любой момент прямо в приложении

Spark Premium (по желанию):
• Безлимитные лайки и суперлайки
• Смотри, кто тебя лайкнул и кто смотрел профиль
• Отмена свайпа, буст профиля на 3 часа
• Невидимый просмотр и значок Premium

Подписку можно отменить в любой момент в Google Play.

## Контент приложения (ответы на анкеты)

### Доступ к приложению
Все функции требуют входа → «Доступ ограничен», указать тестовый аккаунт для проверяющих
(email + пароль; создать отдельный аккаунт с заполненным профилем, не личный).

### Реклама
Приложение **не содержит рекламы**.

### Целевая аудитория
Только **18 лет и старше**. Приложение не привлекает детей.

### Возрастной рейтинг (IARC)
- Категория: социальные сети / общение (знакомства)
- Пользователи общаются друг с другом: **да** (чат, фото)
- Пользователи видят местоположение друг друга: только город, без точных координат
- Покупки цифровых товаров: **да** (Premium)
- Насилие, наркотики, азартные игры, нецензурная лексика в контенте приложения: **нет**
- Есть модерация, жалобы и блокировка: **да**

### Безопасность данных
Шифрование при передаче: **да** (HTTPS). Удаление данных: **да** — в приложении и по ссылке
https://spark-dating.club/account-deletion. Передача третьим лицам: **нет**
(Railway, Sentry, Google Play и Stripe — обработчики данных, это не «передача»).

| Тип данных | Собирается | Зачем | Обязательно |
|---|---|---|---|
| Имя | да | функции приложения, персонализация | да |
| Email | да | управление аккаунтом, связь | да |
| ID пользователя | да | функции приложения, управление аккаунтом | да |
| Другая личная информация (возраст, пол, описание) | да | функции приложения | да |
| Сексуальная ориентация (кого ищет) | да | функции приложения | да |
| Приблизительное местоположение (город) | да | функции приложения | нет |
| Фото | да | функции приложения | да |
| Сообщения в приложении | да | функции приложения | нет |
| История покупок | да | функции приложения | нет |
| Взаимодействия в приложении (лайки, просмотры) | да | функции приложения, аналитика | да |
| Журналы сбоев, диагностика | да | аналитика (исправление ошибок) | да |

### Приложение для знакомств — особые требования
- Возраст 18+ при регистрации ✔
- Пожаловаться / заблокировать ✔
- Удаление аккаунта в приложении и по веб-ссылке ✔
- Без фейковых анкет: **в рабочей базе не должно быть профилей из `seed_bots.py`**
